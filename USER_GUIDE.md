# Minerva Ambassador Portal - User Guide

## Quick Start Guide

### Accessing the Portal
1. Open your web browser
2. Navigate to the portal URL (http://localhost:3000 for local development)
3. You'll see the main dashboard with an overview of all your activities

### First-Time Setup

#### Step 1: Add Schools
1. Click on "Schools Database" from the dashboard
2. Click "Add School" button
3. Fill in the school information:
   - Name (required)
   - Country (required)
   - City (required)
   - Address, website, type
   - Priority level (High/Medium/Low)
   - Status (Not Contacted, Contacted, etc.)
4. Click "Add School" to save

#### Step 2: Add Counselors
1. Navigate to "Counselors Database"
2. Click "Add Counselor"
3. Enter counselor details:
   - First and last name
   - Email and phone
   - Position (e.g., College Counselor)
   - Select school from dropdown or enter manually
   - LinkedIn profile (optional)
   - Relationship strength
   - Preferred contact method
4. Save the counselor

#### Step 3: Schedule Your First Visit
1. Go to "Visits & Events"
2. Click "Schedule Visit"
3. Fill in visit details:
   - Type (School Visit, Workshop, etc.)
   - School/Organization name
   - Location and date
   - Time and duration
4. Set status (Planned/Confirmed)
5. Save the visit

## Module-by-Module Guide

### Dashboard
**Purpose**: Central hub for all activities

**Features**:
- Quick statistics (schools, counselors, students, visits)
- Upcoming visits preview
- Follow-ups due
- Quick access links to all modules

**Best Practice**: Check the dashboard daily to stay on top of follow-ups and upcoming visits.

---

### Schools Database
**Purpose**: Manage all schools in your region

**Key Features**:
- Add/edit/delete schools
- Filter by country, priority, status
- Search by name or city
- Export to CSV
- Track contact history

**Workflow**:
1. Research top schools in a country
2. Add them to the database with priority levels
3. Mark as "Not Contacted" initially
4. Update status as you progress through outreach
5. Add notes about each interaction

**Tips**:
- Set priority to "High" for IB schools and top-ranked institutions
- Use the notes field to record key contacts and visit outcomes
- Update "Last Contact Date" after each interaction
- Set "Next Follow-Up Date" to stay organized

---

### Counselors Database
**Purpose**: Maintain relationships with school counselors

**Key Features**:
- Comprehensive contact information
- Relationship strength tracking
- Preferred contact method
- LinkedIn integration
- Export capabilities

**Workflow**:
1. Add counselor after initial contact
2. Mark relationship as "Cold" initially
3. Update relationship strength as it develops:
   - Cold → Warm → Strong → Champion
4. Log all interactions
5. Set follow-up reminders

**Tips**:
- Always personalize outreach based on preferred contact method
- Champions are counselors who actively promote Minerva
- Keep LinkedIn profiles updated for easy networking
- Export regularly for backup

---

### Students Database
**Purpose**: Track prospective student leads

**Key Features**:
- Student contact information
- Engagement level tracking
- Interested majors
- Source tracking
- Achievement records
- Application status

**Workflow**:
1. Add student immediately after meeting them
2. Record source (Fair, School Visit, Competition, etc.)
3. Note interests and achievements
4. Track engagement level:
   - Cold → Interested → Highly Interested → Applied → Admitted
5. Update application status
6. Set follow-up dates

**Tips**:
- Record specific achievements (olympiad medals, research projects)
- Note interested majors for personalized follow-up
- Track graduation year to time outreach appropriately
- Use engagement level to prioritize follow-ups

---

### Email Templates
**Purpose**: Professional, pre-written email templates

**Available Templates**:
1. **Counselor Introduction**: First contact with a counselor
2. **Counselor Follow-Up**: Following up after no response
3. **Student Reconnection**: Reaching out after meeting at an event
4. **Workshop Invitation**: Inviting schools to host a workshop
5. **Family Discussion**: Inviting families to information session
6. **Olympiad Winner**: Reaching out to competition winners
7. **Application Support**: Offering help with applications

**How to Use**:
1. Select template type
2. Fill in placeholder fields (names, dates, locations)
3. Click "Generate Email"
4. Review and customize further if needed
5. Copy to clipboard
6. Paste into your email client

**Tips**:
- Always personalize with specific details
- Reference specific achievements or conversations
- Include your Calendly link
- Keep emails concise and focused
- Follow up 5-7 days after initial contact

---

### Workshop Materials
**Purpose**: Comprehensive presentation materials

**Content Includes**:
- 60-90 minute workshop outline
- Detailed information on all five majors
- Concentrations for each major
- Key skills developed
- Career pathways
- Interactive activities
- Talking points

**Workshop Structure**:
1. **Introduction (10-15 min)**: Minerva overview, global rotation
2. **Majors Overview (25-30 min)**: Deep dive into each major
3. **Interactive Activity (15-20 min)**: Major matching, Q&A
4. **Application Process (10-15 min)**: Timeline, requirements, next steps

**Tips**:
- Adapt content based on audience (students vs. counselors)
- Use interactive activities to maintain engagement
- Bring printed materials if possible
- Collect student contact information
- Follow up within 48 hours

### Research Tools
**Purpose**: Find talented students and top schools

**Resources**:
1. **Ideal Student Profile**: Characteristics of strong Minerva candidates
2. **Top Schools by Country**: Curated lists of high-performing schools
3. **Academic Competitions**: Links to olympiad websites
4. **Online Platforms**: Communities where talented students gather

**How to Use**:
1. Select a country to view top schools
2. Research competition winners on olympiad websites
3. Look for students on online platforms (Codeforces, AoPS, etc.)
4. Add promising students to the database
5. Personalize outreach based on achievements

**Tips**:
- Focus on students with both depth and breadth
- Look for olympiad participants, not just winners
- Check science fair winners (ISEF)
- Engage with debate champions
- Use publicly available information only

### Visits & Events
**Purpose**: Schedule and track all visits

**Visit Types**:
- School Visit
- Workshop
- Coffee Chat
- Information Session
- Fair
- Family Discussion

**Workflow**:
1. Plan visit and add to calendar
2. Status: Planned → Confirmed → Completed
3. Record attendees and leads generated
4. Mark if follow-up required
5. Update status after visit

**Tips**:
- Schedule 4-6 weeks in advance
- Confirm 1 week before
- Bring business cards and materials
- Collect student emails
- Send follow-up within 48 hours
- Update student database with new leads

---

### Travel Planning
**Purpose**: Organize multi-city trips

**Features**:
- Trip planning
- Transportation tracking
- Accommodation management
- Budget tracking
- Expense recording

**Workflow**:
1. Plan trip with dates and destinations
2. Add transportation details (flights, trains)
3. Add accommodation information
4. Set budget
5. Track actual costs
6. Update status: Planning → Booked → In Progress → Completed

**Tips**:
- Book 4-6 weeks in advance for best prices
- Consider rail passes for multi-city trips
- Build buffer time between visits
- Keep all booking confirmations
- Track expenses for reporting
- Plan efficient routes

**Features**:
- Export all data as JSON
- Import from backup

- Cross-device transfer

**Workflow**:
1. **Regular Backup**: Export weekly

3. **Transfer**: Export from old device, import to new

## Common Workflows

### Workflow 1: School Outreach Campaign
1. Research top schools in target country (Research Tools)
2. Add schools to database (Schools)
3. Find counselor contacts (online research)
4. Add counselors to database (Counselors)
5. Generate introduction email (Email Templates)
6. Send emails and log interactions
7. Schedule visits for interested schools (Visits)
8. Follow up with non-responders after 1 week

### Workflow 2: Post-Fair Follow-Up
1. Add all student contacts to database (Students)
2. Mark source as "Fair"
3. Generate reconnection emails (Email Templates)
4. Send personalized emails within 48 hours
5. Set follow-up dates for 2 weeks later
6. Track engagement level changes
7. Offer application support to highly interested students

### Workflow 3: Competition Winner Outreach
1. Research olympiad results (Research Tools)
2. Find student contact information
3. Add to database with achievements (Students)
4. Generate olympiad winner email (Email Templates)
5. Personalize with specific achievement
6. Send email
7. Follow up with interested students
8. Connect with current Minerva students in same field

### Workflow 4: Regional Trip Planning
1. Identify schools to visit in region (Schools)
2. Create travel plan (Travel)
3. Schedule visits with confirmed schools (Visits)
4. Book transportation and accommodation
5. Prepare workshop materials (Workshops)
6. Conduct visits
7. Update visit status to "Completed"
8. Add student leads from visits
9. Send follow-up emails
10. Track expenses

## Troubleshooting

### Data Not Saving
**Problem**: Changes aren't being saved
**Solution**: 
- Check browser's LocalStorage is enabled
- Try a different browser
- Export data before troubleshooting
- Clear browser cache and reload

### Lost Data
**Problem**: Data disappeared
**Solution**:
- Check if you're using the same browser
- Import from most recent backup
- Check if browser data was cleared
- Set up regular export schedule

### Can't Find a Record
**Problem**: Can't locate a school/counselor/student
**Solution**:
- Use search function
- Check filters are not too restrictive
- Try different search terms
- Check if accidentally deleted

### Export Not Working
**Problem**: Export button doesn't work
**Solution**:
- Check browser allows downloads
- Try different browser
- Check popup blocker settings
- Try exporting smaller datasets

## Appendix: Field Definitions

### School Fields
- **Priority**: Importance level for outreach
- **Status**: Current relationship stage
- **Type**: Public, Private, International, Charter

### Counselor Fields
- **Relationship Strength**: Cold, Warm, Strong, Champion
- **Preferred Contact Method**: Email, Phone, LinkedIn, In-Person

### Student Fields
- **Engagement Level**: Cold, Interested, Highly Interested, Applied, Admitted
- **Source**: How you met the student
- **Application Status**: Current stage in application process

### Visit Fields
- **Type**: Category of visit/event
- **Status**: Planned, Confirmed, Completed, Cancelled
- **Follow-up Required**: Whether additional contact is needed
